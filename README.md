# Ghazal Boutique — Frontend Preview

واجهة عربية RTL مكتملة لعرض تصور موقع غزل بوتيك على العميل.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا من داخل هذا المجلد:

```bash
python -m http.server 8765
```

ثم افتح `http://localhost:8765`.

## الملفات

- `index.html`: بنية الصفحة والمحتوى.
- `styles.css`: الهوية البصرية والتجاوب والحركات.
- `script.js`: قائمة الهاتف، مؤثرات الظهور، تصفية المعرض والعرض المكبّر.
- `assets/`: الصور الأصلية المأخوذة من حزمة العميل.

## ملاحظات التسليم

- أزرار WhatsApp والهاتف والبريد والحسابات الاجتماعية تعمل بالبيانات المؤكدة.
- نموذج الحجز يحمل أسماء حقول واضحة ومسار `data-api-endpoint="/api/bookings"` لربطه لاحقًا بالباكند.
- الخريطة مدمجة، مع زر منفصل لفتح الموقع في تطبيق الخرائط.
- تمت مراجعة التجاوب بصريًا على الهاتف الصغير، الهاتف، التابلت، سطح المكتب والشاشات الكبيرة.
- لم تُضف أسعار أو سياسات تأجير أو حجز غير معتمدة.
- قبل الإطلاق الرسمي يفضّل استبدال صور الحملات بصور أصلية عالية الدقة واعتماد الشعار بصيغة SVG/PNG شفافة.
